# Kompetansematrise Filler

Helps fill out Variant's competency matrix (kompetansematrise) by reading your CV and work history, then suggesting scores for each competency area.

## Used MCP Tools

Expects access to MCP tools "get-cv-for-consultant" and "search-cv-by-keyword" from https://github.com/varianter/mcp-internal.

## Usage

Invoke the skill and provide context about your background. The skill will guide you through the matrix and suggest appropriate levels based on your experience.
